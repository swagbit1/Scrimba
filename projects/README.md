# Archived Scrimba Exercises

Each folder is an individual course exercise. Folder names describe the concept or application rather than the original Scrimba archive identifier.

| Folder | Main concepts |
| --- | --- |
| vite-starter-exercise | Vite project setup, HTML, CSS, JavaScript |
| typescript-vite-exercise | TypeScript types, generics, arrays, functions |
| gift-genie-backend-exercise | Express, client/server requests, environment variables, Markdown sanitization |
| car-dealership-sql | SQL DDL, DML, CRUD, PGlite |
| car-dealership-crud | SQL CRUD and schema updates |
| car-dealership-inline-query | SQL inserts, updates, deletes, PGlite |
| wild-horizons-api | Node.js HTTP API, path and query parameters |
| from-the-other-side-api | HTTP routing, static files, JSON bodies, input sanitization |
| spiral-sounds-store | Express, SQLite, bcrypt, sessions, protected routes, cart workflow |

The project names and descriptions preserve their course context. They should support discussions of learning progress, not replace the larger independently built projects in my portfolio.
