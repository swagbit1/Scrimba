# Scrimba Learning Projects

This repository contains my completed and in-progress exercises from Scrimba's frontend, backend, AI, and database learning paths.

The projects are kept as learning artifacts. They demonstrate the concepts I practiced, but they are not presented as production applications or independent client work.

## Existing work

- API_Routing_Node: Node.js HTTP routing, static-file serving, request-body parsing, input sanitization, and JSON data handling.
- Building API: Node.js API routing with query parameters and path parameters.
- Databases_scrim: SQL schema design, CRUD operations, table changes, and queries run with PGlite.
- geography_game: a file-based JavaScript geography game exercise.

## Published exercise archive

The projects directory collects the additional Scrimba work previously saved as course archives:

- vite-starter-exercise: introductory Vite project structure.
- typescript-vite-exercise: TypeScript types, generics, object modelling, and queue/order operations.
- gift-genie-backend-exercise: an in-progress client-to-server AI request migration exercise using Express, OpenAI SDK conventions, Markdown rendering, and DOMPurify.
- car-dealership-sql: SQL schema, seeded car data, CRUD work, table changes, and query exercises with PGlite.
- car-dealership-crud: an earlier focused CRUD and schema-alteration exercise.
- car-dealership-inline-query: a compact PGlite exercise with inline inserts, updates, and deletes.
- wild-horizons-api: a Node.js HTTP API with query and path parameter filtering.
- from-the-other-side-api: a Node.js HTTP app with static serving, GET/POST routes, JSON body parsing, and sanitization.
- spiral-sounds-store: an Express and SQLite storefront exercise with session-based authentication and cart routes.

## Running a project

Each project is independent. Open its directory, install the dependencies listed in its package.json, then use its documented start command. Some course exercises are intentionally incomplete, especially the Gift Genie backend migration exercise. They are included to show the concepts I worked through, not to claim a finished product.

## Public-source note

Secrets, local environment files, dependencies, and generated SQLite databases are excluded. Configure local values such as SPIRAL_SESSION_SECRET, AI_KEY, and AI_URL through environment variables before running the relevant exercises.
